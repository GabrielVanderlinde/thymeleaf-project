# Projeto Spring Boot com Thymeleaf

Aplicação Java para praticar o desenvolvimento web com Spring Boot e templates renderizados pelo Thymeleaf, com integração a banco de dados relacional.

## Tecnologias

- Java 21
- Spring Boot
- Thymeleaf
- Spring Data JPA
- Bean Validation
- MySQL
- Maven

## Como executar

### Pré-requisitos

- JDK 21
- Maven
- MySQL, conforme a configuração do projeto

Clone o repositório:

```bash
git clone https://github.com/GabrielVanderlinde/thymeleaf-project.git
cd thymeleaf-project
```

Configure a conexão com o banco de dados nas propriedades da aplicação. Evite armazenar senhas reais no repositório.

Execute:

```bash
mvn spring-boot:run
```

## Funcionalidades

O projeto utiliza templates Thymeleaf e persistência com JPA. Para conhecer as telas, entidades, rotas e operações disponíveis, consulte os controllers, templates e repositórios do código-fonte.

## Objetivo

Praticar aplicações web com Java, Spring Boot, templates server-side e persistência de dados.
